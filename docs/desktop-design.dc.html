State sheet

every route inherits these eleven states

One vocabulary for loading, emptiness and failure, so no screen invents its own. Skeletons keep the real layout, empty states name the one useful next action, failures never blame a field unless a field is at fault.

01 · Route loading

Paper-toned blocks in the real layout, no spinner and no shimmer. Header and tabs render immediately; only the list waits. Announced as busy.

02 · Unexpected error
We couldn’t load this page. Please try again. If it keeps happening, the board may be temporarily unavailable.
RetryGo to the board

Replaces the failed region, not the whole chrome. Retry refetches in place. No status codes or stack traces are shown, and nothing is claimed about what did or did not reach the server.

03 · Not found
404 This page doesn’t exist The link may be wrong, or the board may have moved to a new address. Go to the landing page

One state for an unknown product slug, a feedback ID that belongs to another board, and public feedback the owner has hidden. Identical wording in all three — it never reveals that something exists but is hidden.

04 · Empty public board
No feedback yet Be the first to say what Orbit CLI should do next. Add feedback

Filters and sort are hidden while the board has no items — there is nothing to narrow. A guest pressing Add feedback still gets the sign-in popover.

05 · No results after filtering
All 24In Progress 0
Nothing matches this filter There are 24 items on the board under other statuses. Reset filters

Distinct from an empty board: the filter bar stays, the counts stay visible and Reset filters returns to All + Newest, clearing the query string. The dashboard uses the same state.

→ Unknown product slug, a feedback ID that does not belong to the board in the URL, and hidden public feedback all resolve to 03 · Not found. Hidden items are not a separate public state, so a stale link cannot tell the difference between removed and never existed.

→ Emptiness is answered in three different ways depending on cause: nothing exists yet (04, 06, 07, 08), the filter excludes everything (05), or the request failed (02). Each has its own wording and its own next action.

→ Loading and error states belong to the region that owns the data. The header, tabs and board identity never disappear behind a full-page spinner.
